```powershell

```

测试使用安装的 Arm Compiler 6 编译实际 `tool_mode.c`、`flash_data_save.c`，抽取实际用户初始化/目标处理和 `pwm_set` 函数，并在 Unicorn Cortex-M0 中运行。TM1650键盘应答和Flash物理写擦由模拟硬件替代，Flash模拟保持仅允许1→0编程的约束。当前构建输出位于 `.planning/2026-11-09-scene3-current-duty/control-tests/`。测试镜像链接在 `0x08010000`，以免较大的测试代码覆盖真实地址的30/31页模拟Flash；生产镜像地址不受影响。

2026-11-06情景到位停机回归的输出目录为 `.planning/2026-11-06-scene-seat-stop/control-tests/`。
到位测试抽取实际 `user_screw_seat_stop_handle()`、`user_oc_handle()`、`user_state_control()` 和故障锁存函数。2026-11-09同步当前参数：2挡严格超过20A/50ms、3挡严格超过25A/100ms，启动前150ms屏蔽，低电流样本将到位计数减1；运行许可失效才清零计数。覆盖49/50及99/100样本边界、运行许可、模式/方向/挡位切换和松扳机解除锁存。
现有多级积分峰值过流参数为60A/800ms、70A/100ms、80A/10ms。测试用714码最小超过80A，在第11帧积分达到32768，并验证该帧优先撤销电机许可，阻止到位第100份样本触发。主机模拟不代表已完成实际螺丝负载或力矩验证。

2026-11-09新增正转情景3挡平均电流降速回归：电流严格大于18A门限160码并连续200ms才将目标锁为30%（562），等于160码不累计，正常目标仍为100%（1874）。首次观察161码开始计时，199ms正常、200ms降速；确认期间任一低于/等于门限、运行许可、AVG校准或故障门控失效均清计时，同毫秒重复前台查询不增加时间。已降速后同次扣动电流回落或运行许可暂失效仍保持锁存，松扳机、初始化、模式/档位离开3挡或换向清锁存及待确认计时。覆盖其他模式、真实AVG独立零偏及VCC增益、100%→30%→100%软坡和原故障安全门控。完整套件现有60个用例。

覆盖双模式切换和独立档位、按下/释放三样本去抖、按住不重复、ACK失败保持锁定、未知/组合键、各档扳机端点与中间值、真实PWM斜坡、安全保存门控、半写/CRC损坏回退、双页51槽换页和擦写失败、版本/字段范围拒绝、序号回绕与旧三半字记录迁移。

2026-11-05后续回归增加扳机按住屏蔽K2/K3、松扳机后按键释放重按、失败读键不能解锁以及未完成去抖被短扣动打断。挡位期望同步当前38/58/78/100%设置，斜坡等待次数同步既有6次中断/步进1参数；生产调速及斜坡配置未改动。

参数化脚本编译实际模式/LED模块，分别验证默认及覆盖配置。调速1～4档累计亮LED8、8+7、8+7+6、8+7+6+5，默认显存期望为0x40/0x60/0x70/0x78；覆盖灯号参数后期望为0x08/0x48/0x58/0x78。覆盖头仅参与测试；正转情景默认18/100/100%，单灯序8/7/6，反转情景默认单亮LED5、100%保持850ms后降15%。覆盖配置还改变反转灯号、升降占空比和保持时间，以验证配置实际生效。
