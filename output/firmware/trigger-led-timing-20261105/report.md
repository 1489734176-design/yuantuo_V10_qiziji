# 扳机按键与灯光计时固件 — 2026-11-05

- 情景1/2/3档红灯为LED7、LED6、LED5（DIG2，0x20/0x10/0x08）。
- 扳机按住期间K2/K3无效；松开扳机后，按键须先稳定释放，再重新按下才生效。
- 电量LED1..3每次扳机重新扣动亮5s。松手或持续扣住均继续计时；满5s熄灭，只有再次松开并扣动才重启5s。
- 休眠时间为松开扳机后15s；重新扣动清零休眠计数，按住保持唤醒。模式灯及VCC直供LED4保持到休眠。
- 修改配置：SLEEP_TIME=15000ul；新增BATTERY_LED_TIME=5000u。现有调速38/58/78/100%和PWM斜坡参数保留。
