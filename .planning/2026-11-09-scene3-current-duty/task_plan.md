# 情景3档18A降至30%实施计划

> 使用 executing-plans 内联实现；并行代理只核对电流与维护独立测试文件。

**Goal:** 正转情景3档运行电源电流连续大于18A满200ms，目标占空比锁存为30%；松扳机重按恢复该档正常目标。

**Architecture:** 沿用 tool_mode_duty 和独立零偏/VCC校准的 IBusAvgScene_Adc；新增单次扣动降速锁存，实际PWM仍走原软坡及保护。

**Tech Stack:** 裸机C、Keil Arm Compiler 6、现有真实ARM C回归。

## 设计与约束

- 用户已指定行为，直接修改原始.c/.h，新增/修改函数写中文函数头注释，不用Python重写生产源码。
- 用户后续指定消抖：正转情景3档严格大于18A连续200ms才降速；只在有效MOTOR_RUN且电流校准有效时计时。
- 使用现有1ms中断mode_clock_ms计时，不按前台重复调用次数累计；电流等于/低于门限或计时期间许可/校准/故障失效立即重新计时。
- 电流降低或短暂电机许可撤销不清除本次锁存；松扳机、换向、模式/档位离开3档、初始化清除。
- 原到位停机与原过流/温度/欠压/堵转/看门狗保护继续优先控制电机使能及实际输出。
- 选择在现有模式模块控制目标；不改底层PWM保护，不持久化单次扣动状态。
- 电流门限与降速占空比集中在USER/inc/parameter.h；正常目标仍使用TOOL_SCENE_GEAR3_DUTY_PERCENT。
- 当前目录原文件为用户指定目标，不创建worktree，不提交无关文件；构建输出隔离到本任务build。

## Review Focus
