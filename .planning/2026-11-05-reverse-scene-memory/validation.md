# 反转情景4档与双向记忆验证记录

## 实现行为
- 反转K3在调速/情景间切换，反转情景固定4档，DIG2红色LED5；K2仍切调速或循环调速1～4。
- 调速灯1～4档分别亮LED8、LED8+7、LED8+7+6、LED8+7+6+5，情景仍为单灯。
- 正转保持既有K2/K3行为。正反转分别保存当前模式及挡位；真实换向时双方都为调速则沿用离开方向当前档位，涉及情景则恢复目标方向记忆。首次上电直接恢复开关所在方向。
- 反转情景目标100%，实际PWM达到100%后保持850ms，再经原下降斜坡到15%持续运行；松扳机/停止/撤销许可后重新执行。
- 沿用现有升降斜坡：16kHz，每6次PWM中断增减1计数；周期1874，15%为281计数。15%到100%单向约597.4ms，最终波形需实板确认。
- Flash版本2保持20字节槽、CRC16、最后提交标志、双页轮换和完全停机保存门控；兼容版本1和旧挡位日志。
