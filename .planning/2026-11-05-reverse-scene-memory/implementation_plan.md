# 反转情景4档与方向记忆实施计划

**Goal:** 实现反转情景4档、LED5、100%保持850ms后同斜率降15%，正反转分别恢复模式及档位。

**Architecture:** 当前方向选择独立设置。曲线仅改变目标占空比，实际PWM沿用原软启动和保护；PWM输出更新捕获首满值、毫秒中断提供计时。Flash保持原事务日志尺寸，以版本2打包双向设置，并读取版本1。

**Tech Stack:** 裸机C、Cortex-M0、Keil AC6、真实ARM源码的Unicorn行为测试。

## Constraints and decisions
- 按用户要求直接修改本工作目录的原始C/H，增加中文函数头注释。
- 正转情景键保留原逻辑，反转情景键切换调速/情景；反转情景档固定4。
- 850ms从实际占空比首次达到100%计时；松扳机、停机、撤销运行许可、换向后重新执行。
- 参数集中在parameter.h。上下坡复用现有各6次PWM中断变化1计数。
- 保持已有Flash掉电记忆，正反转独立保存；旧记录归入正转，反转默认调速1档。
- 主代理写生产源码及摘要，测试代理写测试；本次不提交Git、不烧录。
